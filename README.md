# Population Group Wise Deposits – EDA
📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a Population Group Wise Deposits dataset. The objective is to understand deposit patterns, account distribution, population groups, and regional variations using Python and data visualization.
# Dataset
The dataset contains 14,037 records and 11 columns.
Main Columns
year – Year of the record
state_name – State name
district_name – District name
region – Region
population_group – Rural, Semi-urban, Urban, Metropolitan
no_of_offices – Number of banking offices
no_of_accounts – Number of accounts
deposit_amount – Deposit amount
# Tools & Technologies
Python
Pandas
Matplotlib
Jupyter Notebook / Google Colab

# Key Insights
The dataset contains 14,037 records with no missing values.
Deposit amount shows a right-skewed distribution with high-value observations.
Number of accounts also shows a right-skewed distribution.
Boxplots indicate the presence of outliers in numerical variables.
Deposit amounts vary across different population groups and regions.
Year-wise analysis helps identify changes in total deposits over time.
# Conclusion
The analysis shows that deposits, accounts, and banking offices have considerable variation across regions and population groups. EDA and visualization help identify distribution patterns, outliers, and trends in the dataset.
